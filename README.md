# DouyinDown

一键下载抖音 UP 主**全部作品**（无水印、最高码率），按 UP 主自动分文件夹，带断点续传、下载台账和补采清单。

界面是本地网页（`http://127.0.0.1:8765`），双击 `启动.bat` 即开，不用装任何东西。

---

## 它解决什么问题

抖音早期的作品列表接口可以用自己造的 `a_bogus` 签名直接请求，这条路现在**已经死了**——社区主流项目（如 `jiji262/douyin-downloader`，9.7k star）的 README 里明确写着请求校验会拦住所有命令行抓取，且"刷新 cookie 或重试都修不好"。抖音官方开放平台又只对已授权账号开放，分页上限 150 条。

本项目的做法是：**用真实浏览器自己发请求，我方只拦截响应**。

- `a_bogus` 由浏览器里的 `webmssdk.js` 自行计算，签名、cookie、设备指纹天然合法，不需要逆向任何算法；
- 我方只读取 `aweme/v1/web/aweme/post` 的响应体，解析出无水印直链；
- 代价是需要扫码登录一次，并且抓取串行（persistent context 不能并发）。

这条路径的可行性是实测出来的，不是推测：登录态下打开主页、把**所有可滚动容器滚到底**，能连续翻页拿到 14 页 / 252 条，`max_cursor` 一路递减、`has_more` 恒为 1，说明 1.3 万条也能翻完。只用 `mouse.wheel` 增量滚动会卡在 36 条——这个坑已经踩过并绕开。

## 快速开始

1. 解压到任意目录（**路径不要带中文以外的怪字符**，建议纯英文路径）。
2. 双击 `启动.bat`，浏览器会自动打开界面。
3. 点右上角「登录抖音」，在弹出的窗口里扫码（只需一次，登录态会长期保存）。
4. 粘贴 UP 主主页链接，点「一键拉取全部作品」。
5. 拉完后点「下载该作者全部待下载」。

> 抓取 1.3 万条这种量级需要较长时间（每页 18 条、每轮约 4 秒），建议先用「条数上限」填 200 试水。

## 界面

四个页签在同一行：

| 页签 | 作用 |
|---|---|
| **UP主批量** | 粘贴链接拉全量、按作者看作品封面网格、批量入队下载、清空台账 |
| **下载记录** | 台账全量列表，**直接显示封面图**，可按状态/关键词筛选 |
| **补采清单** | 下载完成后自动比对台账与磁盘，缺失的落这里，可一键重推或清空 |
| **运行状态** | 实时统计、运行日志、下载目录与并发设置 |

## 目录结构

```
DouyinDown/
├─ 启动.bat              # 双击启动
├─ run.py                # 入口：起服务 + 开浏览器
├─ app/
│  ├─ douyin.py          # 抓取层：浏览器拦包、翻页、登录判定
│  ├─ store.py           # SQLite 台账（作者/作品/补采/设置/抓取日志）
│  ├─ downloader.py      # 并发下载、.part 断点续传、按作者分文件夹
│  └─ server.py          # 标准库 HTTP 服务 + 15 个 JSON 接口
├─ web/
│  ├─ index.html
│  └─ static/            # app.css / app.js
├─ data/                 # 登录态、douyin.db
└─ download/             # 下载产物，按 UP 主分文件夹
```

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 登录态、抓取进度、下载队列、统计 |
| GET | `/api/logs` | 运行日志 |
| GET | `/api/authors` | 已入库作者 |
| GET | `/api/works` | 作品台账（支持 sec_uid / 状态 / 关键词筛选） |
| GET | `/api/reclaims` | 补采清单 |
| GET | `/api/cover?url=` | 封面代理（解决防盗链） |
| POST | `/api/login` | 打开登录窗口 |
| POST | `/api/fetch` | 拉取某作者全部作品 |
| POST | `/api/download` | 入队下载 |
| POST | `/api/download/stop` | 停止下载 |
| POST | `/api/verify` | 比对台账与磁盘，生成补采 |
| POST | `/api/reclaims/clear` | 清空补采清单 |
| POST | `/api/reclaims/push` | 补采重新推送 |
| POST | `/api/settings` | 下载目录 / 并发 |
| POST | `/api/works/delete` | 清空某作者台账（不删文件） |

## 常见问题

**登录窗口没弹出来**
本机若装了 Chrome/Edge 其中之一即可。程序固定用 `channel="msedge"`（Windows 自带 Edge，无需额外下载浏览器内核）。

**抓取只拿到 18 条**
说明当前是游客态。游客只能看到第一页，请先登录。登录判定只认 `sessionid` / `sessionid_ss` / `sid_tt` / `sid_guard` 这几个 cookie，游客的 `ttwid` / `msToken` 不算数。

**下载了一半断了**
重新入队即可，文件走 `.part` + HTTP Range 续传，不会从头下。

**某些作品失败**
抖音直链有时效，链接过期会失败。点「比对缺失」生成补采清单，或重新拉取该作者刷新直链后再下。
